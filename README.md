# مشروع إدارة الديون - المستودع الكامل

هذا المستودع يحتوي على **مكوّنين مستقلّين تماماً**، كل واحد بمجلد خاص به:

## 📱 client-app/
تطبيق العميل (إدارة الديون) — **ملفات ثابتة فقط (Frontend)**، بدون أي اعتماد على Node.js.
يعمل كـ PWA (يمكن تثبيته على الشاشة الرئيسية بالهاتف). يمكن استضافته على أي استضافة عادية
(حتى بدون دعم Node.js إطلاقاً) — فقط ضع الملفات الخمسة بأي مجلد ويب عادي.

- `index.html` — التطبيق كاملاً
- `manifest.json` — إعدادات PWA
- `service-worker.js` — العمل بدون إنترنت
- `icon-192.png`, `icon-512.png` — أيقونات التطبيق

## 🖥️ server-dashboard/
لوحة تحكم البائع + الخادم الخلفي (Backend) + قاعدة البيانات — **يحتاج استضافة Node.js**.

- `server.js` — الخادم الكامل (API + قاعدة بيانات JSON)
- `public/admin/index.html` — لوحة تحكم البائع (Frontend)
- `package.json` — الاعتماديات (Express فقط)
- `data.json` — يُنشأ تلقائياً عند أول تشغيل (قاعدة البيانات)

### التشغيل محلياً
```bash
cd server-dashboard
npm install
npm start
```
ثم افتح: `http://localhost:3000/admin/`
