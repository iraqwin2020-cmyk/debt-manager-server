# خادم تفعيل واشتراكات - برنامج إدارة الديون

خادم Node.js بسيط، قاعدة بيانات JSON حقيقية مدمجة (بدون أي تبعية خارجية لقاعدة بيانات، ويعمل على أي إصدار Node.js — 18 أو 20 أو 22 — وأي منصة استضافة)، للتحكم بتراخيص واشتراكات عملائك.

## المحتويات
- `server.js` — الخادم وكل نقاط الـ API.
- `public/admin.html` — لوحة تحكم البائع (أنت).
- `data.json` — ملف قاعدة البيانات (يُنشأ تلقائياً عند أول تشغيل، تُحفَظ فيه كل بياناتك وتبقى محفوظة حتى بعد إعادة تشغيل الخادم).

## التشغيل محلياً (للتجربة على جهازك)
```bash
npm install
npm start
```
ثم افتح: `http://localhost:3000/admin.html`

**بيانات الدخول الافتراضية:** admin / ChangeMe123 — **غيّرها فوراً** (انظر أدناه).

## قبل النشر الفعلي — مهم جداً
غيّر بيانات دخول لوحة التحكم عبر متغيرات البيئة (لا تتركها بالقيم الافتراضية):
```
ADMIN_USER=اسم_مستخدم_قوي
ADMIN_PASS=كلمة_مرور_قوية_وطويلة
```

## النشر على استضافة مجانية (Render مثال)
1. ارفع هذا المجلد لمستودع GitHub (نفس خطوات رفع البرنامج السابقة).
2. اذهب إلى render.com وأنشئ حساباً مجانياً.
3. "New" → "Web Service" → اختر المستودع.
4. Build Command: `npm install` — Start Command: `npm start`.
5. أضف متغيرات البيئة `ADMIN_USER` و`ADMIN_PASS` من تبويب Environment.
6. بعد النشر ستحصل على رابط دائم مثل: `https://your-app.onrender.com`
   - لوحة التحكم: `https://your-app.onrender.com/admin.html`
   - نقطة التفعيل التي يستخدمها تطبيق العميل: `https://your-app.onrender.com/api/activate`

**ملاحظة:** الخطة المجانية بـ Render "تنام" بعد فترة عدم استخدام وتستغرق ثوانٍ للاستيقاظ عند أول طلب — طبيعي وغير ضار، فقط أول تفعيل بعد فترة سكون قد يتأخر قليلاً.

## نقاط الـ API

### للعميل (تطبيق إدارة الديون يستدعيها):
- `POST /api/activate` — body: `{code, deviceInfo}` — تفعيل أول مرة أو تأكيد كود مُفعَّل.
- `POST /api/check-subscription` — body: `{code}` — فحص دوري لحالة الاشتراك.

### للوحة التحكم (محمية بتسجيل الدخول):
- `POST /api/admin/login` — body: `{username, password}` → `{token}`
- `GET /api/admin/licenses` — قائمة كل التراخيص
- `POST /api/admin/licenses` — إنشاء ترخيص جديد
- `POST /api/admin/licenses/:id/renew` — تجديد
- `POST /api/admin/licenses/:id/revoke` — إلغاء
- `POST /api/admin/licenses/:id/reactivate` — إعادة تفعيل

## الخطوة التالية
لربط تطبيق إدارة الديون (ملف HTML) فعلياً بهذا الخادم بدل الشاشة الشكلية الحالية، أخبرني برابط الخادم بعد نشره وسأعدّل شاشة التفعيل بالتطبيق لتتصل به فعلياً.
